id: left-border-status
title: No status conveyed by a left border color
---

## Rule

Do not signal state — success, warning, error, info, active, selected, priority — with a colored `border-left` or any single colored edge stripe on cards, rows, alerts, or list items.

## Instead

Use an explicit status element that carries text, such as a badge or label, paired with an icon and color. Color must never be the only channel that carries the status.
