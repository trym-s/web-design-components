Composition via Slots

Icons with slots accept sub-icons. One shield base + different badges = many composed icons without extra path data.

Slot Definition

The shield icon defines: slots: [{ name: 'badge', position: 'center', size: 0.42 }]. At render time, the component scales and positions the badge icon into the slot. The badge inherits the parent's variation and color.
