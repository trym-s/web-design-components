Usage

Buttons provide visual cues for actions and events. These fundamental components allow users to commit actions and navigate a page flow. Use a Button when a user needs to submit a form, start a new task or action, or trigger a new UI element to appear on the page.

Best practices

GuidancePractices
DoConvey clear action hierarchy: Each surface should only have 1 primary button. A majority of buttons should be in default or flat style.
DoPromote clarity: Consider labels alongside icons where appropriate.
DontOveruse primary or special buttons: Overusing colored buttons will result in a page with less intentionality, create visual confusion and a lack of page hierarchy.
