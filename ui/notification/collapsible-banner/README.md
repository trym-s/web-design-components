# Collapsible Banner

Folds to its title, or lets go entirely.

## Classification

- Category: `notification` — interactive
- Medium: React + TypeScript + Tailwind CSS + Motion
- Entry point: `src/collapsible-banner.tsx`
- Nature: interactive; reuse the behavior and adapt its literal visual values to the target project.

## Files

- `src/collapsible-banner.tsx` — self-contained hook and styled component
- `src/demo.tsx` — upstream replayable documentation demo
- `reference.tsx` — dashboard entry point
